How I'd use this at Ismail Industries

  1. Put every import quote on a landed basis before it is compared, so a cheaper FOB price with dearer freight or a higher duty line does not win by mistake.
  2. Keep the per-carton figure next to each brand's selling price, so commercial and procurement see the same margin when the rupee or a duty rate moves.
  3. Track the open shipments and supplier payments in one place. The system I built for a timber importer does this and recovered about $15K in receivables that nobody was tracking.
