# murtaza-portfolio

Personal site of Murtaza Mustafa. Plain static HTML, deployed on Vercel from the `main` branch.

- `/`, `/case-studies`, `/about`, `/free-process-review`, `/contact`: the portfolio site, generated by `build.mjs`
- `/<company-role>/`: one work-sample or client page per folder (unlisted, not in the sitemap). Not touched by the build.

## Rebuilding the portfolio pages

    OUT_DIR=. node build.mjs          # macOS / Linux / Git Bash
    $env:OUT_DIR="."; node build.mjs   # Windows PowerShell

Set `SITE_URL` (for example `https://example.com`) when a custom domain is connected, so canonical links, Open Graph tags and the sitemap use it.
